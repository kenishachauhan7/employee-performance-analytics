## 📌 Project Overview

This project transforms a raw Employee Master Dataset containing **1,012 employee records** into an interactive Business Intelligence workspace.

Developed as the final deliverable for the IBM BharatCares Internship Program, this project demonstrates an end-to-end analytics workflow, covering data cleaning, statistical analysis, data preparation, dashboard development, and executive reporting.

The objective is to provide HR, Sales, and Finance teams with a consolidated view of workforce performance, sales productivity, compensation patterns, and employee financial wellness.

## ❗ Problem Statement

Employee information is often distributed across multiple spreadsheets containing salary, sales, performance, and loan details.

This fragmentation makes it difficult for management to evaluate employee productivity, compare departmental performance, understand compensation structures, and identify financial wellness patterns.

This project addresses the problem by consolidating employee information into a unified Tableau workspace with interactive dashboards and dynamic filters.

---

## 🗂 Dataset

**Source:** Employee Master Dataset  
**Original Workbook:** `Excel_Practice.xlsx`

| Attribute | Details |
|---|---|
| Total Records | 1,012 employees |
| Departments | 7 |
| Locations | 11 Indian cities |
| Hiring Period | 2015–2025 |
| Data Format | Microsoft Excel |

### Dataset Attributes

- Employee ID and Name
- Department and Location
- Hire Date
- Salary and Bonus Percentage
- Quarterly Sales (Q1–Q4)
- Performance Rating and Category
- Loan Amount and Interest Rate
- Loan Term and Monthly Repayment
- Present Value (PV) and Future Value (FV)
- Sales Standard Deviation

The dataset was cleaned and enriched through 25 structured Excel practice tasks involving data cleaning, feature creation, lookup functions, PivotTables, and statistical calculations.

## 📊 Dashboards

The project consists of four interconnected dashboards sharing common filters.

### 1. Executive Overview

Provides a consolidated view of organizational performance, including:

- Total Employees
- Total Sales
- Average Salary
- Total Compensation
- Average Performance Rating
- Department-wise Headcount
- Hiring Trends
- Top 10 Performers

### 2. Sales Performance

Analyzes employee and departmental sales productivity through:

- Quarterly Sales Trends
- Department-wise Sales Comparison
- Location-wise Sales Analysis
- Salary vs. Sales Relationship
- Top 10 Employees by Sales

### 3. HR Analytics

Provides workforce and performance insights through:

- Employee Distribution by Department
- Hiring Trends
- Performance Ratings by Department
- Salary Distribution
- Location-wise Performance Analysis

### 4. Financial Wellness – Loan Analytics

Explores employee loan and financial patterns through:

- Total and Average Loan Amount
- Average Monthly EMI
- Average Interest Rate
- Loan Distribution
- Salary vs. Loan Relationship
- Interest Rate vs. Loan Amount
- Present Value vs. Future Value
- Employees with the Highest EMI Burden

## ✨ Key Features

- **Interactive KPI Cards:** Five key performance indicators on each dashboard.
- **Dynamic Filters:** Department, Location, Performance Category, and Year of Hire.
- **Multiple Visualizations:** Bar charts, line charts, histograms, donut charts, scatter plots, treemaps, and bubble charts.
- **Cross-Dashboard Navigation:** Seamless navigation between all four dashboards.
- **Unified Data Source:** All dashboards use the same cleaned Employee Master Dataset.
- **Business-Focused Reporting:** Visual insights designed to support HR, Sales, and Finance decision-making.
